    📄 Report template (Word)

    Used for the Word performance report - your logo, header / footer, fonts and heading styles
    ⤓ Current template ⤓ Starter template
    How the template is used
    • Kept from your file: page size and margins, header and footer (logo), fonts, colours and the styles Title, Heading 1, Heading 2, List Bullet, Table Grid.
    • Placeholders filled in anywhere, headers and footers included: {{title}} {{site}} {{tenant}} {{date}} {{author}} {{vms}} {{period}}.
    • A paragraph holding only {{content}} is where the report goes - a cover page before it and an appendix after it are kept. Without it, the template's own text is replaced by the report.
    • Saved in this site's folder and included in ⤓ Export configuration.
